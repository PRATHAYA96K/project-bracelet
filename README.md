## ✦ Overview

**SATTVA** is a luxury digital showcase featuring an authentic 22-piece private intention bracelet collection. Each piece combines natural mineral stones selected for astrological resonance, spiritual grounding, and daily mindful wearing. 

The web application is designed with an artisanal, high-end aesthetic inspired by luxury horology and gemstone houses, built entirely with modern Vanilla web standards.

---

## ✨ Key Features

- **✦ Curated 22-Piece Collection:** High-resolution product showcase detailing mineral composition, astrological associations, chakra alignments, and metaphysical intention.
- **✦ Interactive Category & Intention Filtering:** Effortlessly filter by intentions (Abundance & Career, Protection & Shield, Wisdom & Clarity, Love & Harmony) and stone types.
- **✦ Instant Real-Time Search:** Dynamic search across stone names, intentions, zodiac signs, and piece titles with instant highlighted results.
- **✦ Deep-Linking & Piece Sharing:** Detailed product modal with one-click URL copy and social sharing linking directly to individual pieces (e.g. `?piece=dhanyog-abundance-bracelet`).
- **✦ Direct WhatsApp & Email Inquiries:** Dedicated enquiry form with international dial code selector (defaults to India `+91`), auto-generating structured WhatsApp messages and formatted email drafts.
- **✦ Luxury Glassmorphism & Micro-Interactions:** Custom dark-palette styling, typography powered by *Cormorant Garamond* and *Plus Jakarta Sans*, and smooth UI transitions.
- **✦ Zero-Dependency Architecture:** Pure HTML5, modern CSS3 (Custom Properties, Flexbox, Grid), and modular Vanilla JavaScript (ES6+).
- **✦ Fully Responsive & Fast:** Optimized layout and lightweight footprint tailored for mobile, tablet, and desktop viewports.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/PRATHAYA96K/project-bracelet.git
cd project-bracelet
```

### 2. Run locally
Because SATTVA is built with pure web technologies, no build step or package installation is required:

- **Option A (Direct in Browser):** Simply open `index.html` in any modern web browser.
- **Option B (VS Code Live Server):** Right-click `index.html` and choose **"Open with Live Server"**.
- **Option C (Local Python Server):**
  ```bash
  python -m http.server 8000
  ```
  Then open `http://localhost:8000` in your browser.

## 🌐 Deployment to GitHub Pages

This project is pre-configured for GitHub Pages:

1. Push your changes to the `main` branch:
   ```bash
   git add .
   git commit -m "Add README and project documentation"
   git push origin main
   ```
2. In your GitHub repository, navigate to **Settings** → **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at:
   `https://prathaya96k.github.io/project-bracelet/`
